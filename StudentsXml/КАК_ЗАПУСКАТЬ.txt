КАК ОТКРЫТЬ И ЗАПУСТИТЬ ПРОЕКТ
==============================

1. Распакуйте архив в обычную папку на диске.
   ВАЖНО: не запускайте проект прямо из окна архива (ZIP).
   Windows открывает архив как временную папку, и Visual Studio
   в ней собрать проект не может.

2. Откройте файл с расширением .sln двойным щелчком
   (например CalculatorMVC.sln). Именно .sln, а не папку.

   Если открывать через саму Visual Studio:
   Файл -> Открыть -> Проект или решение -> выбрать файл .sln
   НЕ используйте пункт "Открыть папку" — в этом режиме
   Visual Studio не собирает проект и выдаёт ошибку
   "не содержит статический метод Main, подходящий для точки входа".

3. Дождитесь, пока в правом нижнем углу закончится восстановление
   пакетов NuGet (для работ 3 и 4).

4. Нажмите F5.

ЧТО ДОЛЖНО БЫТЬ УСТАНОВЛЕНО
---------------------------
Visual Studio 2022 с рабочей нагрузкой
"Разработка классических приложений .NET" (.NET desktop development).
Она включает .NET 8 SDK, Windows Forms и WPF.

Visual Studio 2019 не подойдёт: она не поддерживает .NET 8.
Если менять версию нельзя, откройте файл .csproj и замените
    <TargetFramework>net8.0-windows</TargetFramework>
на
    <TargetFramework>net6.0-windows</TargetFramework>

ГДЕ НАХОДИТСЯ ТОЧКА ВХОДА
-------------------------
Работа 1 (Windows Forms): метод Main в файле Program.cs.
Работы 2, 3, 4 (WPF): метод Main создаётся автоматически из App.xaml.
Для этого файл App.xaml должен лежать в корне проекта и иметь
свойство "Действие при сборке" = ApplicationDefinition.
Проверить: щёлкнуть App.xaml в обозревателе решений -> окно Свойства.
